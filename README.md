# ANARCHIA.PL landing page

Lightweight static site for the ANARCHIA.PL roleplay server.

## Preview locally
1. Run a simple HTTP server, for example: `python -m http.server 4173`.
2. Open [http://localhost:4173](http://localhost:4173) in your browser; the landing page is at the root.

## Files
- `index.html`: hero, feature, rules, and connectivity sections describing the server.
- `style.css`: all the visual styles and responsive layout rules.

No build steps or dependencies are required—just drop the files on any static host.
